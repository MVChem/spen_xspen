# 鼠类 MRI 数据

本目录对应用户指定的两次数据查找会话，收录本机已有数据的符号链接和旧服务器原始文件的本地副本。导入日期：2026-09-14。

| 数据 | 入口 | 来源会话 |
|---|---|---|
| 实验室鼠类采集文件 | [lab_mouse](lab_mouse/README_260914.md) | `01a09f0a-f236-7ca3-96f1-84bf06cc493e` |
| 网上下载的鼠类 MRI 发布原件 | [public_rodent_mri](public_rodent_mri/README_260914.md) | `01a09ec8-c005-7852-a0e6-0978c94fc33f` |

实验室分支已复制 721 个扫描目录及父层元数据，约 19.76 GB，另链接已有 CEST 原始 ZIP；14,588 个文件的 SHA256 均与源端一致。公开分支包含 11 个来源（10 个小鼠来源及补接的大鼠 ds002870）、452 条符号链接，1989 个原件及元数据文件已计算 SHA256；其中 810 个是 MRI 图像文件，不等于独立动物数。全部 453 条数据链接有效。

实验室库沿用既有盘点中的 rat、mouse、mice 范围，不把名称中的 `mouse` 作为物种已核实的标记。原始采集文件保留远端目录层次、文件名与内容，包括已有的扫描仪重建 `pdata`。公开数据保留下载的发布文件；发布者可能已经重建、配准或插值，不能一概称为扫描仪原始 k-space。

本次仅复制、建立符号链接、记录来源和做文件完整性核验，没有重建、归一化、缩放、配准、切片导出或训练划分。公开数据中的序列未确认、其他序列及部分下载分别标记，不能把全部来源统称为 FSE/RARE。

来源记录随数据放在各子目录中，包含原路径、公开数据源标识、文件大小和 SHA256。符号链接依赖源位置继续存在；后续实验请把输出写入对应代码项目的 `runs/`。
