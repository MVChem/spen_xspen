图像显示说明

每个扫描的全部 slice、volume 和 echo 均直接列在下方，索引从 0 开始。向下滚动即可查看，点击任何图像可放大。

原始 ADC 采用 log(1 + RSS)、p1–p99.5 窗口；RO FFT 和重建图采用 RSS、0–p99.5 窗口。各图独立设窗，亮度不能直接用于定量比较。预览按原像素缩放，不作平滑。

RO FFT 与重建预览沿用旧图集的翻转方向；ADC 与扫描仪图保留原方向，不定义解剖方向。未做相位校正的结果单独标注；未提供的方法显示原因。NPZ 数值和坐标保持原样。
